# frontend-design

Generate distinctive, production-grade frontend interfaces that avoid generic AI aesthetics.

## When to apply

Apply this skill automatically whenever working on frontend UI, components, landing pages, dashboards, or any visual interface task.

## Core Approach

Before writing code, establish a clear aesthetic direction:
- Understand the purpose and audience of the interface
- Select a tonal direction (brutalist, maximalist, retro-futuristic, refined minimalism, etc.)
- Identify what makes this interface memorable and specific to its context
- Note technical constraints (framework, existing design system, etc.)

**Guiding principle**: "Choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work — the key is intentionality, not intensity."

## Design Priorities

### Typography
- Use distinctive, characterful fonts rather than defaults (no Arial, no generic Inter)
- Establish a clear typographic hierarchy
- Consider variable fonts, display fonts, or unconventional sizing scales

### Color & Theme
- Build cohesive palettes with a dominant color and sharp accent(s)
- Define everything via CSS custom properties for consistency
- Avoid generic purple gradients or teal-on-dark defaults

### Motion & Animation
- Implement CSS animations with intentional, high-impact moments
- Use staggered entrance animations, scroll-triggered effects
- Animate with purpose — every motion should feel earned

### Spatial Composition
- Embrace asymmetry, overlap, and unexpected layouts
- Use negative space deliberately
- Break out of predictable grid patterns when the context warrants it

### Visual Details & Atmosphere
- Add depth through textures, gradients, subtle patterns
- Create contextual effects (blur, glow, grain) that reinforce the theme
- Polish micro-interactions and hover states

## Anti-Patterns — Never Do This

- Generic AI-generated aesthetics (overused font families, clichéd purple/blue gradients)
- Predictable card-grid layouts with no visual character
- Cookie-cutter designs that ignore the specific context and purpose
- Decorative elements that don't reinforce the interface's concept
- Defaulting to safe, common patterns instead of making a distinctive choice

## Implementation Philosophy

Match implementation complexity to the aesthetic vision:
- Maximalist designs warrant elaborate, layered code
- Refined minimalism requires restraint and precision — less is intentional
- Always ship working code; aesthetic ambition must not compromise functionality
