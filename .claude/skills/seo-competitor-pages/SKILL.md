# seo-competitor-pages

Create high-converting competitor comparison and alternatives pages targeting competitive search intent.

## Page Types

1. Direct "X vs Y" comparisons
2. "Alternatives to X" lists
3. Category roundup pages
4. Feature comparison tables

## Content Structure

- Balanced feature-by-feature analysis with clear verdicts
- Title formulas: `[A] vs [B]: [Key Differentiator]`
- Position CTAs: above fold, after comparison tables, at conclusion
- Include customer testimonials and migration case studies

## Schema Implementation

```json
// Direct comparison → Product with AggregateRating
// Software tools → SoftwareApplication
// Roundup pages → ItemList
```

## Critical Requirements

- All competitor information must be verifiable from public sources
- Include current pricing with update timestamps
- Clearly state which product is yours (affiliate disclosure)
- Never make false claims
- Cite all sources; test competitor features when feasible
- Acknowledge competitors' legitimate strengths
