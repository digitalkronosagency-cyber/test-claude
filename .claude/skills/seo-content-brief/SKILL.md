# seo-content-brief

Research-backed content briefs enabling writers to outrank current top results. Supports new page creation and existing page improvement.

## 5-Stage Process

1. Determine brief mode (new vs. improve)
2. Fetch business context via homepage and sitemap
3. Analyze SERPs with competitor scoring (Depth, Formatting, SEO, UX)
4. Classify search intent
5. Build customized brief

## Critical Rules

**Website Relevance Rule:** Every heading, subtopic, keyword, and FAQ MUST be something the target website can credibly write about based on its actual services or products.

**Site Structure Coverage Rule:** Hub pages must reference every relevant product/service category with internal link suggestions.

**Output Language:** Write for business owners and content writers. No researcher names, framework names, or tool brand names in output.

## Keyword Guidance

- **Primary keyword density**: 0.5–2.0% of total word count
- Must appear in: title tag, H1, URL slug, meta description, first 100 words, at least one image alt text
- **Secondary keywords**: 5–8 closely related terms, distributed naturally
- **Semantic terms**: 10–15 broader context terms

## Meta Tag Standards

- Title tags: 50–60 characters, primary keyword first
- Meta descriptions: 130–150 characters, active voice with CTA

## Output Format

Briefs include: Search Intent, Competitor Analysis table, Content Gaps, Winning Outline (per-section word counts + keyword guidance), Meta Tags, Unique Angle, E-E-A-T Requirements, Internal Linking Opportunities.
